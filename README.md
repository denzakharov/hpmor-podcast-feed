The podcast: https://hpmorpodcast.com

The original podcast has intro and outro in each episode.

This repo contains a feed file for listening to Harry Potter and the Methods of Rationality podcast, in the audiobook form. The whole book is broken down into 6 parts by the HPMOR podcast team. The audio files are hosted by the same team. This podcast feed allows you to listen to these audio files in a podcast app.

To listen to the podcast, copy and paste the following URL to your podcast player:
https://denzakharov.github.io/hpmor-podcast-feed/HPMOR.xml
